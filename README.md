AI-powered healthcare management system built with React, Node.js, Express, and MongoDB. Features secure patient and doctor dashboards, appointment scheduling, prescription management, availability tracking, authentication, analytics, and an intelligent AI healthcare assistant.


# 🏥 MediCare AI

A modern AI-powered Healthcare Management System built with React, Node.js, Express, and MongoDB. The platform provides separate dashboards for Patients and Doctors, enabling appointment management, prescriptions, medical records, and AI-assisted healthcare support.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/medicare-ai.git
cd medicare-ai
```

### Install Dependencies

Frontend:

```bash
npm install
```

Backend:

```bash
cd server
npm install
```

---

## 🔧 Environment Variables

Create a `.env` file inside the server directory:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret_key
```

---

## ▶️ Run Application

### Start Backend

```bash
cd server
npm run dev
```

### Start Frontend

```bash
npm run dev
```

Application will run at:

```text
Frontend: http://localhost:3000
Backend : http://localhost:5000
```
